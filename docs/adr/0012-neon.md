# ADR-0012 — Neon como PostgreSQL

## Status

Aceito

## Contexto

Vercel + PG gerenciado. Auth do Supabase não entra no MVP.

## Decisão

**Neon** (free tier) como banco. `DATABASE_URL` nas env da Vercel.

## Consequências

- Driver serverless (pool / `neon()` HTTP) na hora de implementar.
- ADR-0003 permanece válido; este escolhe o provedor.
